网络访问

局域网访问（同一 Wi-Fi）

允许手机/平板访问

开启后同一局域网内的设备都能打开并使用本助手（含文件与命令工具），请只在自己可信的网络开启。改动需重启程序后生效；首次开启时 Windows 防火墙弹窗请点「允许访问」。

远程接入（公网中继）

允许外网设备访问

经自建网关的加密中继（端到端 AES-256-GCM，网关只见密文）从外网访问本助手；手机入口为网关配对页（下方地址含配对密钥，收藏即可自动连接）。改动即时生效；知道配对密钥的人都能使用本助手，请妥善保管密钥。

设备号

手机入口路径 /a/设备号，在网关上按凭据登记、须唯一；每台安装默认自动生成，可改成自己好记的（2~32 位字母/数字/中划线/下划线）。远程接入开启时改名需网关在线确认（防止把登记凭据改脱节），改名后旧入口失效，记得让手机扫新二维码。

配对密钥

端到端加密密钥的种子，同时是接入凭证：32 位随机字符，只能点「自动生成」换新、不可手填；换新后旧入口链接立即失效，已配对的手机要扫新二维码或收藏新入口。

网关地址 / 端口

中继网关的域名或 IP 与端口，不带 http:// 前缀；给别人分发本软件时，这里应改成对方自己部署的网关。

联网搜索（web_search）

搜索服务

AI 联网搜索走的 /api/search 网关：填了就用这个地址（可指到外网或另一台 jxai-server），留空则跟随上面的「市场服务器」同源。只接受 http(s) 地址，填好即用、改动即时生效（下次搜索就走新地址，不用重启）。这条网关就是下面列表里的「公司网关」供应商。

搜索供应商（按顺序回落：一家失败才换下一家）

按顺序逐个尝试，只有失败才回落下一家（网络/DNS 错误、超时、HTTP 非 2xx、响应解析失败）；成功但 0 条结果不回落——空结果也是答案。总耗时是预算（默认 20 秒，5–120），不是每家超时相加。点「编辑」可改 Key / 地址 / 能力，点「测试」直接打一次真实搜索，看耗时与结果条数。

对话历史与压缩

原始历史永久保留、可随时查回，压缩只影响发给模型的内容。规则自动压缩按间隔触发：自上次压缩后新增未压缩内容达到间隔（默认 40 万）就做一次零成本规则折叠，压缩后增量归零、天然不会反复触发；间隔填 0 或留空＝关闭规则自动压缩。保留字数设 0＝连最近一轮也不保留（每次触发即全量压缩）。模型阈值（默认 80%，对上下文窗口的百分比）仍是最后防线：折叠后估算仍达线才生成模型摘要。间隔与保留字数共用同一计量单位（字数或 token；token 用模型返回的实际用量差值，不估算）。折叠保留用户输入与正文原文、工具调用简化为带编号的动作行（编号即数据库序号，可一步查回原文），写入类参数默认原样保留；丢弃思考过程与环境快照，图片卸载为标注行。

组件

组件 = 本栈原生的外围扩展（前后端自包含，走同一个组件桥）。开关即时热生效，无需刷新页面，也无需重启服务。

技能

技能 = 带说明与脚本的能力包。支持把 .zip 压缩包、单个 .md 说明文件或整个技能文件夹直接拖进本页安装，免开文件选择框。

自带技能 常开，不可删除

用户技能 可开关、可删除

MCP 连接器

MCP 连接器 = 接入本机的一个 Model Context Protocol 服务（设计软件桥、数据服务等），一个连接器可带几十个工具。对话中模型只看到连接器清单，需要时再查工具用法并调用（连接器进程平时不运行，首次调用自动启动、约需数秒）——不占开头的工具目录，也不打扰其他会话的缓存。添加并启用 = 信任该连接器的全部工具。支持把 .json 配置文件（{"mcpServers":{...}} 或 {"名":{...}} 形态，与 Claude Desktop/Cursor 通用）直接拖进本页导入；公司市场的 MCP 条目在「市场 → MCP」里一键安装。

已装连接器 可开关 / 测试 / 展开 工具清单 / 删除

设计软件桥目录 一键安装：下载代码 + 建独立虚拟环境 + 装依赖 + 注册（约 1–3 分钟）

插件
