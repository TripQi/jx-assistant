# 子对话下拉菜单对齐主对话——改动说明与验证步骤

## 背景与目标

右栏「子对话」下拉列表的条目原来只能点击切换，没有任何管理入口。目标：与主对话
会话列表完全对齐——悬停出「更多」（⋯）按钮、支持右键，菜单动作同一套：重命名 /
标为未读 / 分支对话 / 移入回收站（主对话本来就没有置顶，无需排除任何项）。移入
回收站的子对话在回收站视图可见、可恢复、可彻底删除。

## 改动点（web/app-right.js、web/app-left.js、web/style.css）

1. **下拉项菜单**（app-right.js）：renderSubDDPop 每项加 ⋯ 悬停按钮与右键监听，
   新增 `openSubItemMenu(s, rect)`——四个动作与主对话 openSessionMenu 逐项同款
   （同一批 API：PATCH title / PATCH unread / POST fork / PATCH archived），差别只在
   落地刷新面（下拉清单、右栏当前子对话、顶部标题）与「正看着的子对话被回收时
   右栏回空态」。分支沿用 forkFromAnswer 口径（fork 保留 parent，新会话仍是本主
   对话的子对话，就地打开）。
2. **下拉过滤已归档**（app-right.js）：refreshDrawer 过滤 `archived`，移入回收站
   的子对话不再出现在下拉（恢复后回来）。
3. **未读闭环**（app-right.js）：下拉状态格三态（运行中圆环 > 未读红点 > '·'）；
   openSubSession 打开即视为已读（与主对话 openSession 同款，本地与远端一起清）。
4. **回收站支持子对话**（app-left.js）：
   - renderBin 纳入「单独归档的子对话」（父对话还在正常区）；父也归档的不单独
     列，随父整组恢复/清空（原连坐口径）。条目标题前加「子对话」来源小胶囊
     （复用时间线视图的工作区胶囊样式 .s-ws）。
   - collectEmptyTargets（清空回收站）补上单独归档子对话，与 renderBin 同口径。
   - restoreSession 恢复后补调 refreshDrawer，右栏下拉清单立刻回来。
5. **样式**（style.css）：drawer-item 悬停出 row-acts（与主对话会话行同款交互，
   悬停时挡住时间位）；未读红点 `#d33`（与主对话 .dot.unread 同色）。

## 验证步骤（已实测通过，2026-10-19）

隔离目录 `-webdir web` 实例，浏览器实测：

1. 下拉每项悬停出 ⋯；点 ⋯ 与右键弹同一菜单，四项齐全（移入回收站为红色危险项）。
2. 标为未读 → 状态格变红点；打开该子对话 → 红点自动消失（本地+远端）。
3. 重命名 → 顶部下拉按钮标题与清单即时更新。
4. 分支对话 → 新子对话「xx（分支）」创建并就地打开，继承历史正常。
5. 移入回收站（非当前）→ 下拉消失、右栏不受影响；（当前）→ 右栏回空态、
   placeholder 切回「发消息自动新建子对话…」。
6. 回收站视图 → 子对话带「[子对话]」标记显示；恢复 → 回到子对话下拉；
   彻底删除 → 从列表与数据库消失，其余会话不受影响。

## 已知既有竞态（本次未修，仅记录）

loadSessions 异步返回才换内容——约百毫秒窗口期内对旧列表条目点「更多」会按
新视图的菜单处理（如在正常列表残留项上弹「恢复/彻底删除」）。测试中曾误触
（旧主对话条目上弹了回收站菜单）。低频、既有行为，建议后续在菜单弹出时校验
条目当前视图归属再修。
