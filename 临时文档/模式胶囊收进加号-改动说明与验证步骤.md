# 模式胶囊离场动画（收进加号按钮）- 改动说明与验证步骤

> 2026-10-18 · 前端改动（`web/app-chat.js` 一个文件，后端零改动） · 构建方式：`go build`（前端经 go:embed 内嵌，替换正在运行的 exe 后生效）

## 改了什么

切换工作模式时（如 编程 → 标准办公），输入框工具栏上的**琥珀色模式胶囊**（编程/新手编程的「计划」开关、创建技能的「录制」按钮）原来是**瞬间消失**。现在改为播放一段约 0.4 秒的**漏斗三段式**离场动画，让人一眼看出胶囊是"进入了加号里面"：

1. **原位瘪成细线**——宽度略收、高度骤压到 12%，胶囊瞬间压成一条细横线（漏斗入口，加速）；
2. **细线滑进加号**——保持细线形态平移到加号中心，宽度继续收窄（漏斗收口，匀速）；
3. **立起融入**——在加号处高度回弹立起（略过冲再落定）同时淡出（减速），像被加号"吞进去又立起来"。

> 二改说明：一版是"整体缩小+平移"两帧动画，看着像整个框往左飘，感觉不到"进入加号"；按反馈改为上述三段。

## 实现方式（取向：稳，不出 bug 优先）

新增 `vanishIntoPlus(el, view)`（app-chat.js，`applyModeUI` 上方），`applyModeUI` 里原来两处 `classList.add('hidden')` 改为调用它。要点：

1. **原件立刻隐藏**——布局当场回到真实状态。飞走的只是一枚克隆的"幽灵"元素（fixed 挂 body、`pointer-events:none`），不参与布局、不可交互。
2. **幽灵绝不堆积**——新动画开始前先移除旧幽灵；动画结束（onfinish/oncancel）自动移除；另有 600ms 兜底定时器。快速连续切换模式时，页面上同时最多只有 1 个幽灵。
3. **任何异常都退回"瞬间隐藏"**——浏览器不支持 Web Animations API、元素或加号按钮不在屏上、系统开了"减弱动态效果"（prefers-reduced-motion）时，直接走原来的隐藏路径，动画纯锦上添花，永远不挡正确的最终状态。
4. 幽灵克隆时会去掉 id（不与原件撞 id），z-index 200（压过消息流、让开弹层 240/侧栏 210）。

## 验证（已做）

二版（漏斗三段）在本地静态服务器 + Edge 实测全部通过：

- 关键帧三段结构逐帧核验：①原位 `scale(.85,.12)` 无平移（瘪成细线）→ ②`translate(-128px) scale(.28,.12)`（细线精确滑到加号中心）→ ③`scale(.13,1.18)` 过冲 → `scale(.13,1)` 落定 + opacity 0（立起融入）；分段 easing（骤压加速/滑行匀速/立起减速）生效；
- **快速连切 10 次模式（40ms 间隔，含 skill-create 录制按钮同样离场）：幽灵并发始终 ≤ 1，结束后零残留**；
- 原件切换瞬间即隐藏、终态正确（标准办公 = 胶囊隐藏）；切回编程胶囊复活、开关可正常点击切换计划模式；无重复 id、无 DOM 污染；`node --check` 语法通过。

## 手工验证步骤

1. 双击新编译的 坚祥数字助理GO.exe；
2. 首页输入框上方点「模式」胶囊 → 选「编程」→ 权限芯片右侧出现琥珀色「计划」胶囊；
3. 再点「模式」→ 选「标准办公」→ 观察琥珀色胶囊缩成一条线收进左侧 ➕ 按钮（约 0.3 秒）；
4. 反复快速切换 编程/新手编程/创建技能/标准办公 若干次：每次只有一枚胶囊在飞、结束后无残影、布局无跳动；
5. 切回「编程」：胶囊重新出现，点它能正常开关计划模式。
