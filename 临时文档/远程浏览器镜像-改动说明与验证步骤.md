# 远程浏览器镜像（右栏「浏览器」的远程只读直播）· 改动说明与验证步骤

2026-11-01 · 会话：编程模式助手

## 需求与设计一句话

远程接入（手机 / 外网电脑 / 局域网其他设备打开同一 UI）时，右栏「浏览器」不再只是一句
「浏览器面板仅在桌面版可用」，而是把**家端浏览器面板的画面**以帧流镜像过来只读显示：
家端是唯一渲染权威，远程只是它的照片直播——**仅同步、不操控**。

- 帧格式：**WebP q60**（CDP `Page.captureScreenshot` 就地压缩，比 PNG 小一个量级）；
- 帧率：前端每帧后至少隔 **500ms** 再取下一帧（≈2fps）；后端另有 **450ms 最小重截间隔**，
  多客户端 / 异常高频请求都命中缓存帧，不挤占 UI 线程；
- 省流量：内容 SHA-256 指纹去重——页面静止时连续轮询只回 `changed:false`（几十字节）；
  **没人轮询就不截图**（懒截图），收起右栏 / 切走视图即停轮询，零流量零开销；
- 显示：默认**等比缩放、内容居中、装不下的方向留深色边**；新按钮「⛶」切换
  **原始像素 1:1 + 滚动条**（`safe center` 防居中布局裁掉左/上溢出），偏好记 localStorage。

## 工具栏换装（仅远程形态）

| 控件 | 远程形态行为 |
|---|---|
| 标题行 | 固定提示语「远程仅同步查看 · 操作请在电脑前」 |
| ◀ / ▶（后退/前进） | 隐藏（动的是家端浏览器） |
| 地址栏 | 只读（仍实时显示家端当前地址） |
| ⟳ 刷新 | 变义：**立即取一帧**；若正看 iframe 预览页（交付卡「右侧查看」），点击回到镜像 |
| ↗ 外部打开 | 保留：用**远程这台设备自己的**浏览器打开当前网址（原网页形态行为） |

| 打开方式 / 📁 定位 | 隐藏（文件在家端，远程看不见） |

家端浏览器未打开时：镜像区显示「电脑端浏览器未打开」。

## 协议要点（远程端拿来即用）

```jsonc
GET /api/browser/frame?session=<会话id>&v=<客户端已有版本>
// 浏览器未开 → {"running":false}
// 正常 → {"running":true,"ver":1761988000123,"vw":800,"vh":600,
//          "changed":true,"mime":"image/webp","data":"<base64>"}
// 静止（ver 未变）→ {"running":true,"ver":...,"vw":...,"vh":...,"changed":false}
```

- `ver` 是**毫秒时间戳**（同毫秒内再变则 +1 单调）：JSON 的 float64 往返在 2^53 内精确，
  纳秒会丢精度导致版本永远对不上（单测抓到过）；浏览器关闭重开后缓存重建，版本天然
  不会回退到客户端旧值。
- `/api/` 前缀在远程中继白名单内，公网远程天然可用。

## 已验证 / 未验证

已验证（本机，含隔离桌面壳实例 2026-11-01 20:55–20:58 实测，多实例并行用项目自带的
`JX_DESKTOP_MUTEX` 环境变量换互斥体名 + 独立 dataDir/端口）：
1. `go build` 通过；`go test -run TestBrowserFrame` 全绿；关闭/面板相关既有测试未回归；
2. **真实桌面壳端到端**：隔离实例起桌面版（-desktop），API 导航打开 example.com →
   `GET /api/browser/frame` 返回真 WebP 帧（帧头 RIFF…WEBP，WebView2 控件级 CDP 对
   `format:webp` 支持无误）；OCR 确认 q60 压缩下多语言文字清晰可辨；
3. **静止去重与节流**（真实页面）：页面静止时持版本再取 changed=false（600ms 后真重截，
   指纹相同仍不传帧）；面板矩形落位后 vw/vh 正确回传；
4. **远程形态帧流**（局域网 IP 访问模拟远程客户端）：真实 WebP 帧上屏（natural 尺寸
   = 家端 CSS 视口）、家端导航到新页面后远程画面 1s 内跟随；服务日志显示远程端 2fps
   轮询连续 90 秒稳定无中断；**桌面壳进程全程存活，无 panic、无崩溃**；
5. 远程形态 UI 逐项：环境判定、标题提示语、后退/前进隐藏、地址栏只读、⛶ 显隐与两态
   切换 + localStorage 记忆、刷新按钮（远程义）、视图切走轮询自停/切回恢复、
   「电脑端浏览器未打开」提示；
6. 本机形态回归（127.0.0.1，与桌面壳同代码路径）：浏览器视图完全原样。

未验证（如实说明）：
- 真实公网远程（经 210 网关中继）的完整链路——帧走 `/api/` 白名单天然过中继，
  与其他 /api/ 接口同一通道，风险仅在传输层（与既有远程功能一致）；
- Electron 壳形态（面板桥只出 PNG）暂不支持镜像，端点回 501「当前浏览器形态不支持远程画面镜像」。

## 真机验证步骤（给用户）

> 以下第 1–4 步已在隔离桌面壳实例上自动验证过（2026-11-01），此处留给正式环境复核。

1. 电脑端跑桌面版，随便开一个会话，右栏「浏览器」打开一个网页；
2. 手机远程接入（或局域网另一台设备打开 `http://<电脑IP>:<端口>`）；
3. 远程端右栏切到「浏览器」：应看到家端页面画面（等比缩放居中）；电脑前滚动/点击页面，
   远程画面应在 ~0.5–1s 内跟随；
4. 点 ⛶ 切 1:1 模式：画面按原始像素显示，超出可滚动；再点切回；
5. 电脑端关掉浏览器页面（✕）：远程端显示「电脑端浏览器未打开」；
6. 流量核对（可选）：页面静止时手机端几乎无流量，操作时 ~几十 KB/s。

附：多实例并行测试的方法（本次实测用的）——设环境变量 `JX_DESKTOP_MUTEX=<独立名>`
（项目自带的互斥体覆盖开关，desktop_windows.go acquireSingleInstance）+ `-config`
指向独立 dataDir 的配置 + `-port` 独立端口，即可与正式实例并行跑测试壳。
