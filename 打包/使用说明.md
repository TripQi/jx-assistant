# 坚祥数字助理GO 使用说明

## 安装

双击 `坚祥数字助理GO-安装包.exe`，按向导完成安装（安装到当前用户的
「应用程序」目录，不需要管理员权限）。桌面与开始菜单会创建
「坚祥数字助理GO」快捷方式。

桌面版使用 Windows 自带的 WebView2 运行时显示界面。Windows 10 / 11
一般已内置；若安装时提示缺少，按提示打开微软官方页面装一次即可。

## 启动与使用

- 双击快捷方式（或安装目录里的 `坚祥数字助理GO.exe`）启动，弹出桌面窗口。
- 再次双击不会开第二个窗口，而是把已有窗口调到前台。
- 首次使用：在左下角「设置」中填入模型服务的 API Key（兼容 OpenAI
  chat-completions 接口；baseURL 填 `mock` 可离线体验完整链路）。
- 默认工作目录是安装目录下的「默认工作区」（安装目录不可写时回退
  「文档\坚祥数字助理」），会话能写哪些文件由它决定，可在设置中更换。
  从旧版升级时，原来的「工作区」文件夹会自动改名为「默认工作区」，
  里面的文件不受影响，历史对话照常可用。
- 关闭窗口即退出程序。

## 技能与运行环境

安装包已内置技能所需的便携 Python 运行时（安装目录 `技能\_runtime\`），
PDF、Office 文档、图片 OCR 等技能**开箱即用、无需联网装依赖**。
技能目录缺失或损坏时，程序会在下次启动时自动从内嵌母本恢复。

## 市场：装技能、组件与插件

左侧栏底部点「市场」进入：技能 / 组件 / 插件三个页签，顶部可搜索，
条目上一键「安装」「更新」「卸载」。组件装完立即生效（无需重启）。

首次使用需在 设置 · 网络访问 · 市场服务器 填入市场清单地址
（公司内部市场由服务器管理员提供，形如
`http://服务器:2228/market/manifest.json`）。装好的技能在 设置 · 技能
里开关，组件在 设置 · 内置组件 里开关，Claude 插件在 设置 · Claude 插件
里管理。

## 自带的 MD 查看器

安装时会在安装目录放入 `md-viewer\MD查看器.exe` 并自动完成 .md 文件关联：
装完双击任意 .md 文件即用它打开（独立窗口渲染，带目录导航；首次双击系统
可能弹一次「你要如何打开这个文件？」，选「MD查看器」并勾选「始终使用此应用」）。
未装 WebView2 运行时时自动改用系统浏览器打开，功能不丢。

卸载本软件时会自动取消 .md 关联（恢复安装前的打开方式），并结束驻留
后台的查看器；想单独取消关联，运行 `MD查看器.exe /unregister` 即可。

## 数据与卸载

- 会话记录与配置保存在安装目录的 `data\` 与 `config.json`，仅本机本用户可见。
- API Key 等敏感字段经 Windows DPAPI 加密落盘，绑定当前用户。
- 卸载走「设置-应用」或安装目录里的卸载程序；卸载默认保留你的会话数据，
  想彻底清理请手动删除安装目录。

## 命令行形态（进阶）

```sh
坚祥数字助理GO.exe -desktop            # 桌面模式（默认）
坚祥数字助理GO.exe -browser            # 强制浏览器模式：起服务并打开默认浏览器
坚祥数字助理GO.exe -port 9000 -noopen  # 指定端口、不自动开页面
坚祥数字助理GO.exe sandbox acl-audit   # 沙箱常驻授权审计/清理
```
